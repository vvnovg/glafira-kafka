# 변경 내역

[CHANGELOG.md](../../CHANGELOG.md)의 한국어판입니다. 이전 버전은 해당 파일을 참고하세요. 각 버전의 내용은 'Glafira 정보'에 업데이트 릴리스 노트로 표시됩니다.

## 0.5.2
- LLM 어시스턴트가 읽는 메시지의 마스킹이 더 철저해졌습니다.
  - 텍스트에서 쿠키와 `Authorization` 헤더(`Proxy-Authorization` 포함)의 값은 줄 끝까지 마스킹되므로 모든 쿠키, Digest 매개변수, AWS 서명이 가려집니다.
  - `name=value` 쌍에서 어떤 문자로 쓴 이름이든 인식합니다. 예를 들어 연결의 자체 목록에 있는 키릴 문자 필드 이름입니다.
  - 문자에 붙어 있는 카드 번호(`id4111…`), 드문 방식으로 묶어 쓴 카드 번호, JSON의 음수 및 소수 형태 카드 번호도 찾아냅니다.
- Describe 권한이 없는 토픽: '메시지' 탭과 `read_messages`, `summarize_messages`, `get_group_commit_history` 도구가 '찾을 수 없음' 대신 '작업을 수행할 권한이 없습니다'라고 알립니다.
- `get_group_commit_history`: 커밋 묶음을 빼도 커밋 기록이 100 KB에 들어가지 않으면 어시스턴트는 빈 기록 대신 요청 범위를 좁히라는 조언과 함께 '응답이 너무 큼' 오류를 받습니다. `summarize_messages`는 큰 키를 처리할 때 메모리를 덜 사용합니다.
- 연결 양식:
  - 연결 양식 두 개가 열려 있으면 그중 하나에서 선택한 LLM 접근 수준이 표시되지 않았습니다(저장은 올바르게 되었습니다). 이제 각 양식이 자신의 수준을 표시합니다.
  - 화면 읽기 프로그램이 운영 클러스터의 메시지 내용이 LLM 제공업체로 전송된다는 경고를 읽어 줍니다.
  - MCP 상태를 확인할 수 없으면 '메타데이터 및 메시지'를 선택할 수 없는 이유를 알리는 안내가 표시됩니다.
  - '끔' 및 '메타데이터만' 수준에서 숨겨진 마스킹 목록이 더 이상 저장을 막지 않습니다.
- 연결 트리의 `LLM` 표시: 화면 읽기 프로그램이 'LLM' 대신 'LLM 접근: 메타데이터 및 메시지'처럼 전체 내용을 읽습니다. 텍스트 대비도 높아졌습니다.
- MCP 로그: 연결 목록을 불러오지 못한 경우 "'메시지'에서 열기" 버튼이 사용할 수 없는 이유를 알려 줍니다.

## 0.5.1
- 'Glafira 정보' → '업데이트'의 릴리스 노트가 인터페이스 언어로(번역이 없으면 영어로) 표시되며, 원시 Markdown이 아닌 서식이 있는 텍스트로 표시됩니다. 이는 0.5.1 이상 버전에 제공되는 업데이트에 적용되며, 이전 버전에서는 릴리스 노트가 영어 일반 텍스트로 표시됩니다.
- 변경 내역은 이제 영어로 작성됩니다(`CHANGELOG.md`). 다른 인터페이스 언어 버전은 `docs/changelog/`에 있습니다.

## 0.5.0
- LLM 어시스턴트의 메시지 읽기. 연결의 LLM 접근에는 '끔', '메타데이터만', '메타데이터 및 메시지'의 세 가지 수준이 있습니다. 세 번째 수준에서 어시스턴트는 MCP를 통해 다음을 할 수 있습니다:
  - 시간 범위 또는 오프셋으로 메시지를 읽습니다. 필터는 '메시지' 탭과 같습니다(`read_messages`).
  - 내용 없이 시간 범위를 개괄합니다: 파티션별·시간별 양, 자주 나오는 키, 순서가 어긋난 타임스탬프(`summarize_messages`).
  - 컨슈머 그룹이 언제 어떤 오프셋을 커밋했는지 `__consumer_offsets`에서 확인합니다(`get_group_commit_history`).
- 시간은 시간대와 함께만 전달됩니다. 호출 한 번은 최대 40초 동안 실행되고, 최대 100만 개 레코드를 살펴보며, 최대 100 KB를 반환합니다.
- 어시스턴트에게 전달하기 전 마스킹:
  - 이름 목록(표준 목록 또는 연결 자체 목록)에 있는 필드의 값은 `***` 문자열로 바뀝니다.
  - 이메일 주소, 카드 번호, JWT, 인증 토큰은 모든 텍스트에서 마스킹됩니다.
  - 필터는 마스킹 전 데이터에 적용되므로 로그에 있는 값으로 메시지를 찾을 수 있습니다.
- 접근 수준과 마스킹 목록은 내보내거나 가져오지 않습니다.
- 정책 키 `mcpMessagesEnabled`는 메시지 읽기를 금지합니다. 이 경우 '메타데이터 및 메시지' 수준은 '메타데이터만' 수준으로 동작합니다.
- MCP 로그: 메시지 읽기 호출에서는 토픽 또는 그룹, 살펴본 레코드 중 반환한 양, 마스킹한 값의 수가 표시됩니다. "'메시지'에서 열기" 버튼은 같은 시간 범위와 필터로 '메시지' 화면의 양식을 채웁니다. 정확히 옮길 수 없으면 양식에 그 사실이 표시됩니다.
- MCP: MCP 2026-07-28 프로토콜 클라이언트를 지원합니다(예: Claude Code 2.1.310). 연결할 때 바로 클라이언트 이름을 받고 승인을 요청합니다. 대기 중인 세션에는 '승인' 버튼이 있습니다. 모든 도구가 읽기 전용으로 명시됩니다(`idempotentHint`).
- MCP 레지스트리(Glama)용 카탈로그 서버 `glafira-mcp-catalog`: Docker 이미지와 실제 도구 목록을 제공하며, 호출하면 데스크톱 앱이 필요하다고 응답합니다. README는 영어로 바뀌었습니다(러시아어는 `README.ru.md`).
- LLM 제안에 따른 오프셋 재설정: 쓰기 전에 그룹 구성을 다시 확인합니다. 그사이 그룹에 멤버가 들어와 브로커가 거부한 경우 '그룹이 비어 있지 않음'이라는 알기 쉬운 오류가 표시되고, 재설정 양식에 그룹의 최신 상태가 바로 표시됩니다.
- 인터페이스:
  - 빈 필드의 플레이스홀더는 입력한 값과 헷갈리지 않도록 기울임꼴로 표시됩니다.
  - '메시지' 화면의 시작 위치와 파티션 필드에 포인터를 올리면 도움말이 표시됩니다.
  - 연결 트리의 환경 및 LLM 배지 위에서는 일반 화살표 포인터가 표시됩니다.
- 가이드: 'LLM 어시스턴트(MCP)' 장에 '메시지 읽기' 섹션이 12개 언어로 추가되었습니다.
