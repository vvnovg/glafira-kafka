# Начало работы

Glafira for Apache Kafka — desktop-клиент для кластеров Kafka. В нём можно просматривать топики и consumer groups, читать и отправлять сообщения, сбрасывать оффсеты. В этой главе — установка, первый запуск, локальная Kafka для практики и язык интерфейса.

## Установка на macOS {#install-macos}

Glafira работает на macOS 11 и новее. Установщик — на странице релизов: https://github.com/vvnovg/glafira-kafka-releases/releases

Выберите файл для своего Mac: `aarch64` — для Apple silicon (M1 и новее), `x64` — для Intel.

1. Откройте файл `.dmg`.
2. Перетащите Glafira for Apache Kafka в папку «Программы».
3. Запустите приложение из «Программ» или Launchpad.

Можно использовать и установщик `.pkg`: он ставит приложение в `/Applications` для всех пользователей.

Бета-сборки пока не подписаны Apple, поэтому macOS блокирует первый запуск. Чтобы разрешить его:

1. Попробуйте один раз открыть приложение и закройте предупреждение.
2. Откройте «Системные настройки» → «Конфиденциальность и безопасность».
3. Прокрутите вниз до сообщения о Glafira for Apache Kafka и нажмите «Все равно открыть». Если система попросит, введите пароль.

На macOS 14 и более ранних можно вместо этого сделать правый клик по приложению → «Открыть» → «Открыть».

Если это не помогло, один раз снимите флаг карантина в Терминале:

```bash
xattr -dr com.apple.quarantine "/Applications/Glafira for Apache Kafka.app"
```

Если не открывается сам скачанный `.dmg`, сначала снимите флаг с него:

```bash
xattr -d com.apple.quarantine ~/Downloads/Glafira_for_Apache_Kafka_*.dmg
```

Для обновлений, установленных из самого приложения, эти шаги не нужны.

## Установка на Windows {#install-windows}

Скачайте установщик `.msi` (`x64`) со страницы релизов: https://github.com/vvnovg/glafira-kafka-releases/releases

1. Запустите файл `.msi`.
2. Подтвердите установку в запросе Windows. Приложение ставится для всех пользователей компьютера, поэтому нужны права администратора.
3. Запустите Glafira for Apache Kafka из меню «Пуск».

Бета-сборки пока не подписаны. Если SmartScreen блокирует установщик, нажмите «Подробнее», затем «Выполнить в любом случае». Можно и заранее разблокировать файл в PowerShell:

```powershell
Unblock-File -Path "$env:USERPROFILE\Downloads\Glafira_for_Apache_Kafka_*_x64_en-US.msi"
```

## Установка на Linux {#install-linux}

Сборки для `x86_64` есть в трёх форматах. Скачайте подходящий для вашего дистрибутива со страницы релизов: https://github.com/vvnovg/glafira-kafka-releases/releases

- Debian, Ubuntu и производные: `sudo apt install ./<файл>.deb`
- Fedora, RHEL и производные: `sudo dnf install ./<файл>.rpm`
- Любой дистрибутив: сделайте AppImage исполняемым (`chmod +x <файл>.AppImage`) и запустите его.

После установки пакета запустите приложение из меню приложений или командой `glafira-kafka` в терминале.

Пароли Glafira хранит в Secret Service (например, GNOME Keyring или KWallet). Убедитесь, что один из них запущен в вашем сеансе, — иначе приложение не сможет сохранить пароли подключений.

## Первый запуск {#first-run}

Окно состоит из двух частей. Слева — панель [[ui:sidebar.connections]]. Справа — вкладки: каждый открытый экран, например список топиков или Producer, получает свою вкладку.

Пока подключений нет, в панели показана короткая подсказка, а в области вкладок — предложение добавить подключение. Чтобы начать:

1. Нажмите `+` ( [[ui:sidebar.newConnection]] ) в заголовке панели [[ui:sidebar.connections]].
2. Заполните поля [[ui:connections.form.name]] и [[ui:connections.form.bootstrap]], например `localhost:9092`.
3. Нажмите [[ui:connections.form.test]], чтобы проверить настройки, затем [[ui:common.save]].

После сохранения откроется обзор кластера. Под каждым подключением в панели есть ссылки: [[ui:sidebar.cluster]], [[ui:sidebar.topics]], [[ui:sidebar.groups]], [[ui:sidebar.producer]] и [[ui:sidebar.consumer]]. Все настройки подключения описаны в главе [Подключения](connections.md#create).

Внизу панели — ссылки [[ui:sidebar.settings]], [[ui:tabs.license]], [[ui:sidebar.help]] и [[ui:sidebar.about]]. Знак `?` рядом с полем показывает короткую подсказку о нём. Клавиша `F1` в любом месте окна открывает главу руководства о текущем экране. На macOS руководство есть и в меню «Справка».

Если вы пользовались Kafka Explorer (прежнее название приложения), при первом запуске Glafira скопирует его подключения, шаблоны, историю отправки и лицензию. Пароли тоже копируются из системного хранилища секретов. Уже существующее не перезаписывается, старые данные не удаляются. macOS может один раз спросить доступ к старым записям Keychain.

## Локальная Kafka для практики {#local-cluster}

Чтобы попробовать приложение без общего кластера, запустите Kafka на своём компьютере в Docker. Достаточно одного брокера:

```bash
docker run -d --name kafka -p 9092:9092 apache/kafka:3.9.0
```

Затем создайте подключение: bootstrap-сервер `localhost:9092`, протокол `PLAINTEXT`, окружение `local`. Когда брокер больше не нужен, удалите его командой `docker rm -f kafka`.

В подсказке пустой панели [[ui:sidebar.connections]] упоминается `docker compose -f dev/docker-compose.yml up -d`. Этот файл входит в исходный код Glafira. Если исходный код у вас есть, команда запускает брокер с тремя листенерами:

- `localhost:9092` — `PLAINTEXT`.
- `localhost:9094` — `SASL_PLAINTEXT` с `PLAIN` (пользователи `tester` / `tester-secret` и `admin` / `admin-secret`) и SCRAM (`scram-user` / `scram-secret` для `SCRAM-SHA-256` и `SCRAM-SHA-512`).
- `localhost:9095` — `SSL` с клиентскими сертификатами (mTLS). Тестовые сертификаты — в `dev/certs/out`.

Эти пользователи и сертификаты — только для локальных тестов.

## Язык интерфейса {#language}

Интерфейс доступен на английском, русском, немецком, французском, испанском, итальянском, польском, португальском (Бразилия), китайском (упрощённый и традиционный), японском и корейском. Все языки доступны бесплатно.

Чтобы сменить язык:

1. Нажмите [[ui:sidebar.settings]] внизу левой панели.
2. Выберите язык в поле [[ui:settings.language.label]].

Изменение применяется сразу, в том числе к этому руководству и меню macOS. Вариант [[ui:settings.language.systemUnknown]] (по умолчанию) следует языку операционной системы. Если этого языка нет в списке, интерфейс будет на английском.

## Настройки, заданные организацией {#managed-settings}

В компании администраторы могут задать часть настроек для всех пользователей через политику. Изменить такие настройки в приложении нельзя. Политика может:

- задать язык интерфейса — список языков в [[ui:sidebar.settings]] тогда недоступен, а рядом написано, что язык задан вашей организацией;
- включить Pro ключом организации — на экране [[ui:tabs.license]] тогда написано, что лицензия управляется вашей организацией;
- выключить проверку обновлений или направить её на внутреннее зеркало.

Чтобы узнать, действует ли политика, откройте [[ui:sidebar.about]] и посмотрите строку [[ui:about.policy]]. Если в политике ошибка, она показывается там же и на экране [[ui:tabs.license]]. С вопросами о политике обращайтесь к администраторам. О лицензии и обновлениях — в главе [Лицензия и обновления](license-updates.md).
