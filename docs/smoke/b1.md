# Смоук B1 (локализация en/ru)

`pnpm tauri dev`.

0. Псевдоязык (dev): «Настройки» → «Pseudo (dev)» → пройти все экраны (дерево, вкладки, формы подключения, топики, группы,
   просмотр, Producer, consumer-сессии, «Лицензия», «О программе», диалоги и ошибки). Всё, что не в `[!! … !!]`, — забытая строка;
   смотреть и на переполнение вёрстки. Этот проход делается вручную (в автоматической проверке не выполнялся).
1. Язык ОС — русский: интерфейс по-русски («Настройки» → «Как в системе (Русский)»).
2. «Настройки» → «English» → весь интерфейс сразу по-английски без перезапуска: дерево, вкладки, формы подключения,
   топики, группы, просмотр, Producer, consumer-сессии, «Лицензия», «О программе».
3. Ошибки на английском: подключение к `localhost:1` → «Could not connect to brokers» (подробности — исходный текст);
   неверный пароль PKCS#12 в mTLS-подключении → английский текст ошибки сертификата.
4. Free: в списке языков Deutsch, Français, … с замком, выбрать нельзя.
   С Pro (ключ из docs/licensing.md) — можно выбрать «Deutsch»: интерфейс пока английский (словаря нет до B2).
5. Удалить ключ Pro при выбранном Deutsch → «Настройки»: «Выбранный язык доступен в Pro — сейчас интерфейс на английском».
6. Политика `language = ru` (plist в /Library/Managed Preferences/io.github.vvnovg.glafira.kafka.plist, как в docs/smoke/m3a.md п. 11) →
   перезапуск → язык русский, список недоступен, «Язык задан вашей организацией». Удалить политику.
7. Числа: в списке топиков количество сообщений — «1 234 567» (ru) / «1,234,567» (en).
8. Склонения: «1 сообщение / 3 сообщения / 5 сообщений» там, где выводится число с существительным;
   удаление нескольких топиков: «Удалить 2 топика?» / «Удалить 5 топиков?».
9. Лог `~/Library/Logs/io.github.vvnovg.glafira.kafka/app.log` — сообщения на английском.
