# Смоук B2 (языки de, fr, es, it, pl, pt-BR)

> Примечание (0.3.0): лицензионных ключей и экрана «Лицензия» больше нет, все функции бесплатны; шаги про Pro/Free и лицензию устарели.

> Историческая заметка: в подпроекте E ограничение языков по Pro снято — все языки бесплатны; шаги ниже про «— Pro», Pro-лицензию для выбора языка и переключение на английский без Pro больше не применимы.

`pnpm tauri dev`, Kafka: `docker compose -f dev/docker-compose.yml up -d`.

1. «Настройки» → по очереди Deutsch, Français, Español, Italiano, Polski, Português (Brasil): интерфейс сразу
   на выбранном языке без перезапуска, `document.documentElement.lang` = код языка (`pt-BR` для бразильского).
2. Для каждого языка — проход по экранам из `docs/i18n/review-checklist.md` (раздел «Экраны»): нет английских строк,
   кроме намеренных (`docs/i18n/same-as-en.json`), нет имён ключей вида `topics.list.empty`.
3. Ширина: окно 1400 px и минимальное 900 px. Строки из `node scripts/i18n-check.mjs --lengths` проверить особо:
   кнопки, заголовки колонок списка топиков и групп, вкладки, левая панель. Обрезанное — сократить перевод.
4. Склонения (pl): удаление 1, 2, 5, 22 топиков — «topik», «topiki», «topików», «topiki»;
   сброс оффсетов 1 / 2 / 5 партиций.
5. Числа и размеры по языку (форматирует `Intl`/`toLocaleString`, `src/lib/format.ts`): в списке топиков
   количество сообщений 1234567 — «1.234.567» (de, es, it, pt-BR — точка), «1 234 567» (ru, pl — неразрывный
   пробел U+00A0; fr — узкий неразрывный U+202F). Четырёхзначные числа: «1.234» (de, pt-BR), «1 234» (ru, fr),
   но «1234» без разделителя в es, it и pl (CLDR: группировка с 5 цифр) — это не баг.
6. Ошибки: подключение к `localhost:1` — текст ошибки на выбранном языке, «Подробности» — исходный текст librdkafka.
