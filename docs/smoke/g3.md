# Смоук G3 (предложения LLM в формах)

Сборка: `pnpm tauri dev` (Glafira запущена заранее; MCP-клиент — Claude Code из `~`, как в `docs/smoke/g1.md`, п. 11; клиент подтверждён, у подключения dev-стенда отмечен «Доступ для LLM (только метаданные)»). Локальная Kafka: `docker compose -f dev/docker-compose.yml up -d` — один брокер. Стенд и уборка — те же, что в `docs/smoke/g2.md`.

Подготовка (в терминале):

```bash
docker exec ke-kafka kafka-topics --bootstrap-server localhost:9092 --create --topic smoke-g2 --partitions 1 --replication-factor 1
docker exec ke-kafka kafka-topics --bootstrap-server localhost:9092 --create --topic smoke-g2-isr --partitions 1 --replication-factor 1 --config min.insync.replicas=2
seq 1 3 | docker exec -i ke-kafka kafka-console-producer --bootstrap-server localhost:9092 --topic smoke-g2
docker exec ke-kafka kafka-consumer-groups --bootstrap-server localhost:9092 --group smoke-g2-empty --topic smoke-g2 --reset-offsets --to-earliest --execute
```

1. Хвосты G2. Окружение подключения **prod**, «Проверить кластер». Сменить окружение на **dev** и сохранить: в строке «Последняя проверка: … · в Glafira» появилось « · проверено как PROD». Открыть вкладки «Обзор кластера» и «Замечания» (видна одна), нажать «Проверить кластер» на одной и сразу переключиться на другую: пока идёт проверка, на обеих кнопка «Проверка…» неактивна; после проверки пометки про окружение нет.
2. Контроллер. В «Замечаниях» нет ни «Нет контроллера», ни «Контроллер неизвестен» (брокер один, контроллер известен). Правило «Контроллер неизвестен» (предупреждение) появляется только если `controller id` не пришёл при живых лидерах — на dev-стенде не воспроизводится, проверено автотестами.
3. Предложение по конфигам. В Claude Code: «Проверь здоровье кластера dev и предложи со строгостью warning исправление для smoke-g2-isr» → вызовы `health_check` и `propose_change` (вид `alterTopicConfigs`, `min.insync.replicas` → `1`). На вкладке «Замечания» в разделе «Предложения LLM» карточка: заголовок, обоснование как есть, строка «Конфиги топика: min.insync.replicas → 1», подпись «Предложение LLM · claude-code» (если ассистент передал `relatedRuleId` `topic.minIsrUnreachable` — дальше « · min.insync.replicas больше фактора репликации»). В дереве число в точке у «Замечаний» выросло на 1 (значок считает только «Предупреждение» и «Критично»; при «Информация» число не меняется); на экране топика `smoke-g2-isr` карточка в блоке «Замечания».
4. Применение. «Открыть в форме» → вкладка `smoke-g2-isr`, подвкладка «Конфигурация», редактор открыт, над ним «Применяется предложение LLM: <заголовок>», у `min.insync.replicas` значение `1`, «изменений: 1». «Проверить изменения» → «2 → 1», «Применить». Карточка пропала из блока топика; на вкладке «Замечания» раскрыть «Закрытые (1)»: «применено N секунд назад» (через минуту и дольше — «N минут назад», сразу — «применено сейчас»), или «применено с правками …», если значение поправили. Спросить ассистента «какое решение по предложению?» → `list_proposals` со `status` `closed` или `all` показывает `applied`, `appliedAsProposed: true`.
5. Создание топика. «Предложи создать топик smoke-g3-dlq на 2 партиции с cleanup.policy=compact, фактор репликации не указывай» → `propose_change` (`createTopic`); на вкладке «Замечания» карточка «Новый топик — партиций: 2, фактор репликации: по умолчанию брокера, конфиги: cleanup.policy=compact», имя без ссылки. «Открыть в форме» → вкладка «Топики», форма создания с именем `smoke-g3-dlq`, партиций 2, фактор репликации `-1`, пресет «delete (по умолчанию)», в доп. конфигах `cleanup.policy=compact`, над формой «Применяется предложение LLM: <заголовок>»; «Создать» → открылась вкладка топика, предложение «применено».
6. Партиции. «Предложи увеличить число партиций smoke-g2 до 3» → карточка «Партиций: → 3». «Открыть в форме» → вкладка топика `smoke-g2`, панель добавления партиций: над ней «Применяется предложение LLM: <заголовок>», в поле «Новое число партиций (сейчас 1)» стоит 3. Ввести 4 и «Увеличить» → предложение «применено с правками»; `list_proposals` (`status` `closed` или `all`) — `appliedAsProposed: false`.
7. Сброс оффсетов. «Предложи сбросить оффсеты группы smoke-g2-empty к началу для всей группы» → карточка «Оффсеты группы: С начала (earliest), Вся группа». «Открыть в форме» → вкладка группы, панель сброса со стратегией «С начала (earliest)», область «Вся группа», строка про предложение. «Предпросмотр» → план, «Применить (1)» → результат, предложение «применено». Та же карточка — в блоке «Замечания» на экране группы.
8. Отклонение. «Предложи поставить retention.ms=60000 у smoke-g2» → карточка. «Отклонить» → поле причины, ввести «не сейчас», «Отклонить предложение» → в «Закрытые» статус «отклонено: не сейчас». Спросить ассистента о решении → `list_proposals` (`status` `closed` или `all`) — `rejected`, `rejectReason: "не сейчас"`. «Открыть снова» — карточка снова открыта.
9. Отзыв и повтор. Попросить ассистента отозвать это предложение → `withdraw_proposal`, статус «отозвано». Попросить предложить то же самое дважды: второй вызов отвечает `created: false`, карточка одна.
10. Проверка против кластера. Попросить ассистента предложить изменение конфига несуществующего топика → ответ `not_found`; изменить конфиг `__consumer_offsets`, настаивая на вызове `propose_change` → `invalid_argument` про внутренний топик; уменьшить число партиций `smoke-g2`, настаивая на вызове `propose_change` → `invalid_argument` «newTotal must be greater»; неизвестный ключ конфига (например `retention.msx`) → `invalid_argument` «unknown topic config retention.msx: use names from get_topic_configs». Карточек не появилось.
11. Read-only. Отметить у подключения «Только чтение», сохранить. Попросить предложить изменение конфига `smoke-g2` → ответ содержит `readOnly: true`, карточка есть, кнопка «Открыть в форме» неактивна с подсказкой «Подключение только для чтения». Снять «Только чтение» → кнопка активна.
12. Prod. Окружение **prod**, сохранить. «Открыть в форме» у открытого предложения → после «Проверить изменения» диалог «Применить изменения?» просит ввести имя подключения («Это prod-подключение. Введите его имя …»); «Применить» активна только с верным именем; ввести и применить → «применено». Вернуть окружение **dev**.
13. Фильтры и удаление. «Источник» → «Правила» — разделы «Предложения LLM» и «Замечания LLM» скрыты; «Замечания и предложения LLM» — находки правил скрыты, остаются предложения и замечания LLM. «Удалить все предложения LLM» → в строке «Удалить все предложения LLM у этого подключения?» нажать «Удалить все предложения LLM» → «Предложений LLM нет.», раздела «Закрытые» у предложений нет.
14. Перезапуск. Попросить ещё одно предложение, перезапустить Glafira: карточка на месте. Файл `~/Library/Application Support/io.github.vvnovg.glafira.kafka/health/<id>.json` содержит `proposals` (`-rw-------`).
15. Справка и языки. F1 на вкладке «Замечания» — глава «Проверка кластера и замечания», раздел «Предложения LLM»; F1 в разделе MCP «Настроек» — глава «LLM-ассистенты (MCP)» с разделом «Проверка кластера, замечания и предложения». Переключение языка (12 языков): метки раздела совпадают с интерфейсом, карточка и описание изменения переведены.
16. Журнал MCP. В «Настройках» → «Журнал MCP» строки `propose_change` с результатом «успешно» (у отвергнутых проверкой в п. 10 — код `invalid_argument` или `not_found`). «Показать файл» → в `mcp-audit.jsonl` у строк `propose_change` в `args` есть `connectionId`, `kind`, `target`, `severity`, `relatedRuleId` (`null`, если не передан), нет заголовка, обоснования и значений изменения.

Долги смоука G1 (не проверялись в G1, см. `docs/smoke/g1.md`):

17. Claude Desktop (п. 3 смоука G1): подключение по фрагменту из «Настроек», диалог подтверждения `claude-ai`, вопрос о топиках. После этого п. 3–4 этого смоука можно повторить в Claude Desktop.
18. Ребаланс с мигающим консьюмером (п. 5 смоука G1): `observe_consumer_group` называет входы и выходы участника.
19. Windows (п. 14 смоука G1, release-сборка из CI): шим из GUI-бинаря отвечает, закрытие Claude Desktop не закрывает Glafira; на Windows дополнительно п. 3–4 этого смоука.

Уборка:

```bash
docker exec ke-kafka kafka-consumer-groups --bootstrap-server localhost:9092 --delete --group smoke-g2-empty

docker exec ke-kafka kafka-topics --bootstrap-server localhost:9092 --delete --topic smoke-g2-isr
docker exec ke-kafka kafka-topics --bootstrap-server localhost:9092 --delete --topic smoke-g3-dlq
```
