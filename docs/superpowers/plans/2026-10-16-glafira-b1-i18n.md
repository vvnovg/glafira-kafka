# B1 «Инфраструктура локализации и английский» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Интерфейс и сообщения из Rust переводятся через словари. Готовы английский (базовый) и русский. Язык выбирается на экране «Настройки» с учётом ОС, политики и лицензии Pro. Проверки CI не дают оставить непереведённую строку.

**Architecture:** Фронтенд переводит через i18next по словарям `src/locales/<code>.json`. Rust передаёт не готовый текст, а `key` + `params` и английский `message` как запасной вариант для логов. Выбор языка хранит и проверяет Rust (`settings.json`, политика `language`, Pro-языки). Скрипт `scripts/i18n-check.mjs` сверяет словари между собой и с ключами из Rust, а также ищет забытую кириллицу в коде.

**Tech Stack:** `i18next` + `react-i18next`, `Intl`, Rust (`sys-locale`), node:test для скриптов.

**Спецификация:** `docs/superpowers/specs/2026-10-16-glafira-localization-design.md`. План B2 «Pro-языки» пишется после слияния B1.

## Global Constraints

- Языки: `en` (базовый и запасной), `ru` — Free; `de`, `fr`, `es`, `it`, `pl`, `pt-BR` — Pro. В B1 словари создаются только для `en` и `ru`, Pro-языки появляются в B2, но список языков и проверки Pro делаются уже в B1.
- Приоритет языка: политика `language` → выбор пользователя → язык ОС → `en`. Pro-язык без Pro-лицензии → `en`, выбор пользователя не стирается.
- Сопоставление языка ОС: по основному тегу (`de-AT` → `de`); `pt-*` → `pt-BR`; неизвестный → `en`.
- Отсутствующий ключ показывается по-английски, а не именем ключа.
- Не переводятся: данные пользователя (имена топиков и групп, конфиги), `details` ошибок, логи и архив диагностики (они на английском).
- Шаблоны параметров — `{{name}}`, одинаковые в Rust и в словарях.
- Плюральные формы — суффиксы i18next: `_one`, `_few`, `_many`, `_other`.
- `formatTimestamp` остаётся ISO-подобным и не зависит от языка: это технический формат, удобный для логов и Kafka. По языку форматируются числа и размеры (разделители).
- Существующие тесты компонентов работают с русским: в `src/test/setup.ts` задаётся `ru`. Новые тесты интерфейса используют `ru`, если не проверяют именно язык.
- Ошибки никогда не превращаются в 0 или успех. Подтверждения только на странице. Видимые подписи у полей. Секреты не попадают в логи.
- Коммиты заканчиваются пустой строкой и `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Push только с согласия пользователя.
- Окружение: `source "$HOME/.cargo/env"`. Kafka: `docker compose -f dev/docker-compose.yml up -d`, IT: `KE_IT_BOOTSTRAP=localhost:9092 KE_IT_SASL_BOOTSTRAP=localhost:9094 KE_IT_MTLS_BOOTSTRAP=localhost:9095`.

## Соглашение о ключах

- Интерфейс: `<экран>.<блок>.<элемент>`, например `connections.form.bootstrap`, `topics.list.empty`, `common.retry`.
- Ошибки и сообщения Rust: `errors.<модуль>.<суть>` (`errors.guard.readOnly`, `errors.tls.keyEncrypted`); тексты, которые не являются ошибками, — `messages.<модуль>.<суть>` (`messages.connectivity.tcpOk`).
- Общие слова (Повторить, Отмена, Сохранить, Удалить, Загрузка…, «—» причины) — в `common.*`.
- Русский текст переносится в `ru.json` дословно (это эталон смысла), английский пишется заново: естественный, краткий, термины Kafka по-английски.

- [ ] **Step 3: Скрипт** — `scripts/i18n-check.mjs`:

```js
#!/usr/bin/env node
// Проверки локализации: одинаковые ключи и параметры во всех словарях, ключи из Rust, забытая кириллица в коде.
import { readFileSync, readdirSync, statSync } from "node:fs";
import { join, relative } from "node:path";
import { fileURLToPath } from "node:url";

const PLURAL = /_(zero|one|two|few|many|other)$/;

export function flatten(obj, prefix = "", out = new Map()) {
  for (const [k, v] of Object.entries(obj)) {
    const key = prefix ? `${prefix}.${k}` : k;
    if (v && typeof v === "object") flatten(v, key, out);
    else out.set(key, String(v));
  }
  return out;
}

export function placeholders(text) {
  return [...new Set([...text.matchAll(/\{\{\s*([\w.]+)\s*\}\}/g)].map((m) => m[1]))];
}

function pluralForms(code) {
  const rules = new Intl.PluralRules(code);
  return rules.resolvedOptions().pluralCategories;
}

/** dicts: { en: {...}, ru: {...} } — первый (en) эталон. Возвращает список проблем. */
export function checkDictionaries(dicts) {
  const problems = [];
  const flat = Object.fromEntries(Object.entries(dicts).map(([c, d]) => [c, flatten(d)]));
  const base = flat.en;
  // Базовые ключи без плюрального суффикса и их параметры (по форме _other или самому ключу).
  const baseKeys = new Map();
  for (const [k, v] of base) {
    const stem = k.replace(PLURAL, "");
    const params = new Set(placeholders(v));
    const prev = baseKeys.get(stem);
    baseKeys.set(stem, { plural: PLURAL.test(k), params: prev ? new Set([...prev.params, ...params]) : params });
  }
  for (const [code, map] of Object.entries(flat)) {
    if (code === "en") continue;
    const forms = pluralForms(code);
    for (const [stem, info] of baseKeys) {
      const keys = info.plural ? forms.map((f) => `${stem}_${f}`) : [stem];
      for (const key of keys) {
        if (!map.has(key)) {
          problems.push(`${code}: нет ключа ${key}`);
          continue;
        }
        const got = new Set(placeholders(map.get(key)));
        // В плюральных формах «count» может отсутствовать в _one у некоторых языков — требуем остальные параметры.
        for (const p of info.params) {
          if (!got.has(p) && !(info.plural && p === "count")) problems.push(`${code}: ${key} без параметра {{${p}}}`);
        }
        for (const p of got) if (!info.params.has(p)) problems.push(`${code}: ${key} с лишним параметром {{${p}}}`);
      }
    }
    for (const k of map.keys()) {
      if (!baseKeys.has(k.replace(PLURAL, ""))) problems.push(`${code}: лишний ключ ${k} (нет в en)`);
    }
  }
  return problems;
}

/** files: { path: content }. Кириллица в строках кода фронтенда вне словарей, тестов и комментариев. */
export function findCyrillic(files) {
  const hits = [];
  for (const [path, content] of Object.entries(files)) {
    if (/\.test\.[tj]sx?$/.test(path) || path.includes("/locales/") || path.includes("/test/")) continue;
    content.split("\n").forEach((line, i) => {
      const code = line.replace(/\/\/.*$/, "").replace(/\/\*.*?\*\//g, "");
      if (/^\s*\*/.test(line)) return; // строки JSDoc-блоков
      if (/[А-Яа-яЁё]/.test(code)) hits.push(`${path}:${i + 1}`);
    });
  }
  return hits;
}

function walk(dir, exts, out = []) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) walk(p, exts, out);
    else if (exts.some((e) => p.endsWith(e))) out.push(p);
  }
  return out;
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const root = process.cwd();
  const locales = join(root, "src/locales");
  const dicts = Object.fromEntries(
    readdirSync(locales)
      .filter((f) => f.endsWith(".json"))
      .map((f) => [f.replace(/\.json$/, ""), JSON.parse(readFileSync(join(locales, f), "utf8"))]),
  );
  const problems = checkDictionaries(dicts);
  if (!process.argv.includes("--no-cyrillic-scan")) {
    const files = Object.fromEntries(
      walk(join(root, "src"), [".ts", ".tsx"]).map((p) => [relative(root, p), readFileSync(p, "utf8")]),
    );
    for (const hit of findCyrillic(files)) problems.push(`кириллица в коде: ${hit}`);
  }
  if (problems.length) {
    console.error(problems.map((p) => `✗ ${p}`).join("\n"));
    process.exit(1);
  }
  console.log(`✓ словари ${Object.keys(dicts).join(", ")} согласованы`);
}
```

`src/i18n/index.ts`:

```ts
import i18next from "i18next";
import { initReactI18next } from "react-i18next";
import en from "../locales/en.json";
import ru from "../locales/ru.json";
import { LANGUAGES } from "./languages";

const PSEUDO = "x-pseudo";

/** Псевдоязык (только dev): текст в скобках, длиннее на ~30 % — видно забытые строки и узкие места. */
function pseudo(value: string): string {
  const map: Record<string, string> = { a: "á", e: "é", i: "í", o: "ó", u: "ú", A: "Á", E: "É", O: "Ó" };
  const body = value.replace(/\{\{[^}]+\}\}|[aeiouAEO]/g, (m) => (m.startsWith("{{") ? m : map[m] ?? m));
  return `[!! ${body}${"·".repeat(Math.ceil(value.length * 0.3))} !!]`;
}

void i18next.use(initReactI18next).init({
  resources: { en: { translation: en }, ru: { translation: ru } },
  lng: "en",
  fallbackLng: "en",
  interpolation: { escapeValue: false }, // React уже экранирует
  returnNull: false,
  postProcess: [],
});

if (import.meta.env.DEV) {
  i18next.use({
    type: "postProcessor",
    name: "pseudo",
    process: (value: string) => (i18next.language === PSEUDO ? pseudo(value) : value),
  });
  i18next.options.postProcess = ["pseudo"];
  i18next.addResourceBundle(PSEUDO, "translation", en);
}

if (import.meta.env.DEV) {
  i18next.on("missingKey", (_lngs, _ns, key) => console.warn(`[i18n] нет ключа ${key}`));
}

export const i18n = i18next;

export async function setLanguage(code: string): Promise<void> {
  const known = LANGUAGES.some((l) => l.code === code) || (import.meta.env.DEV && code === PSEUDO);
  await i18next.changeLanguage(known ? code : "en");
}

export function currentLocale(): string {
  return i18next.language === PSEUDO ? "en" : i18next.language || "en";
}
```

```ts
import { currentLocale } from "../i18n";

const num = (n: number, digits = 0) =>
  n.toLocaleString(currentLocale(), { minimumFractionDigits: digits, maximumFractionDigits: digits });

export function formatBytes(n: number): string {
  if (n < 1024) return `${n} B`;
  if (n < 1024 * 1024) return `${num(n / 1024, 1)} KB`;
  return `${num(n / (1024 * 1024), 1)} MB`;
}

export function formatCount(n?: number | null): string {
  if (n === undefined) return "…";
  if (n === null) return "—";
  return num(n);
}
```

```rust
//! Тексты для интерфейса: ключ словаря + параметры + английский текст (для логов и как запасной вариант).
//! Перевод делает фронтенд по `src/locales/<язык>.json`; шаблоны `{{name}}` совпадают со словарём en.

use std::collections::BTreeMap;

use serde::Serialize;

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct LocalizedText {
    pub key: String,
    pub params: BTreeMap<String, String>,
    pub text: String,
}

pub fn render(template: &str, params: &BTreeMap<String, String>) -> String {
    let mut out = String::with_capacity(template.len());
    let mut rest = template;
    while let Some(start) = rest.find("{{") {
        out.push_str(&rest[..start]);
        let after = &rest[start + 2..];
        match after.find("}}") {
            Some(end) => {
                let name = after[..end].trim();
                match params.get(name) {
                    Some(v) => out.push_str(v),
                    None => out.push_str(&rest[start..start + 2 + end + 2]),
                }
                rest = &after[end + 2..];
            }
            None => {
                out.push_str(&rest[start..]);
                rest = "";
            }
        }
    }
    out.push_str(rest);
    out
}

impl LocalizedText {
    pub fn new(key: &str, en: &str, params: BTreeMap<String, String>) -> Self {
        Self { key: key.to_string(), text: render(en, &params), params }
    }
}

/// `ltext!("messages.x.y", "English {{p}}", p = value)` → `LocalizedText`.
#[macro_export]
macro_rules! ltext {
    ($key:literal, $en:literal $(, $name:ident = $val:expr)* $(,)?) => {{
        #[allow(unused_mut)]
        let mut params = ::std::collections::BTreeMap::<String, String>::new();
        $( params.insert(stringify!($name).to_string(), ($val).to_string()); )*
        $crate::i18n::LocalizedText::new($key, $en, params)
    }};
}

/// `app_err!(ErrorCode::X, "errors.m.y", "English {{p}}", p = value)` → `AppError`.
#[macro_export]
macro_rules! app_err {
    ($code:expr, $key:literal, $en:literal $(, $name:ident = $val:expr)* $(,)?) => {
        $crate::error::AppError::localized($code, $crate::ltext!($key, $en $(, $name = $val)*))
    };
}
```

```js
/** Ключи и английские шаблоны из макросов Rust: app_err!(…, "key", "English {{p}}" …) и ltext!("key", "English" …). */
export function rustKeys(files /* {path: content} */) {
  const out = new Map();
  const re = /(?:app_err!\(\s*[^,]+,|ltext!\()\s*"([\w.]+)"\s*,\s*"((?:[^"\\]|\\.)*)"/g;
  for (const content of Object.values(files)) {
    for (const m of content.matchAll(re)) out.set(m[1], m[2].replace(/\\"/g, '"'));
  }
  return out;
}

/** Каждый ключ Rust есть в en.json, текст en совпадает с шаблоном Rust (единый английский). */
export function checkRustKeys(rust, enFlat) {
  const problems = [];
  for (const [key, template] of rust) {
    if (!enFlat.has(key)) problems.push(`en: нет ключа ${key} (используется в Rust)`);
    else if (enFlat.get(key) !== template) problems.push(`en: ${key} отличается от шаблона в Rust: «${enFlat.get(key)}» ≠ «${template}»`);
  }
  return problems;
}
```

```rust
use std::path::{Path, PathBuf};
use std::sync::RwLock;

use serde::{Deserialize, Serialize};

use crate::error::{AppResult, ErrorCode};
use crate::storage::fs::{read_json_or_quarantine, write_json};
use crate::sync::RwLockExt;

pub const LANGUAGES: [(&str, bool); 8] = [
    ("en", false), ("ru", false), ("de", true), ("fr", true),
    ("es", true), ("it", true), ("pl", true), ("pt-BR", true),
];

fn is_pro(code: &str) -> Option<bool> {
    LANGUAGES.iter().find(|(c, _)| *c == code).map(|(_, p)| *p)
}

pub fn match_language(tag: &str) -> Option<&'static str> {
    let primary = tag.split(['-', '_']).next().unwrap_or("").to_ascii_lowercase();
    if primary == "pt" {
        return Some("pt-BR");
    }
    LANGUAGES.iter().map(|(c, _)| *c).find(|c| c.eq_ignore_ascii_case(&primary))
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase")]
pub enum LanguageReason { Policy, User, System, Default, ProRequired }

/// Политика → выбор → ОС → en; Pro-язык без Pro → en (ProRequired).
pub fn resolve(system: Option<&str>, chosen: Option<&str>, policy: Option<&str>, pro: bool) -> (String, LanguageReason) {
    let candidate = policy.map(|p| (p.to_string(), LanguageReason::Policy))
        .or_else(|| chosen.map(|c| (c.to_string(), LanguageReason::User)))
        .or_else(|| system.and_then(match_language).map(|s| (s.to_string(), LanguageReason::System)));
    match candidate {
        Some((code, reason)) => match is_pro(&code) {
            Some(true) if !pro => ("en".into(), LanguageReason::ProRequired),
            Some(_) => (code, reason),
            None => ("en".into(), LanguageReason::Default),
        },
        None => ("en".into(), LanguageReason::Default),
    }
}

#[derive(Serialize, Deserialize, Default)]
#[serde(rename_all = "camelCase")]
struct SettingsFile {
    schema_version: u32,
    #[serde(default)]
    language: Option<String>,
}

pub struct SettingsStore {
    path: PathBuf,
    language: RwLock<Option<String>>,
}

impl SettingsStore {
    pub fn open(dir: &Path) -> Self {
        let path = dir.join("settings.json");
        let language = match read_json_or_quarantine::<SettingsFile>(&path, 1) {
            Ok(f) => f.and_then(|f| f.language).filter(|l| is_pro(l).is_some()),
            Err(e) => {
                tracing::warn!("settings not read: {}", e.message);
                None
            }
        };
        Self { path, language: RwLock::new(language) }
    }

    pub fn language(&self) -> Option<String> {
        self.language.read_safe().clone()
    }

    /// Блокирующий вызов (запись файла). Проверка Pro — в команде (нужна лицензия).
    pub fn set_language(&self, lang: Option<&str>) -> AppResult<()> {
        if let Some(l) = lang
            && is_pro(l).is_none()
        {
            return Err(crate::app_err!(ErrorCode::InvalidInput, "errors.settings.unknownLanguage", "Unknown language “{{code}}”", code = l));
        }
        write_json(&self.path, &SettingsFile { schema_version: 1, language: lang.map(String::from) })?;
        *self.language.write_safe() = lang.map(String::from);
        Ok(())
    }
}

#[derive(Debug, Clone, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct LanguageSettings {
    pub system: Option<String>,
    pub system_match: Option<String>,
    pub chosen: Option<String>,
    pub policy: Option<String>,
    pub effective: String,
    pub reason: LanguageReason,
    pub pro_languages: Vec<String>,
    pub languages: Vec<String>,
}

pub fn system_locale() -> Option<String> {
    sys_locale::get_locale()
}

pub fn language_settings(system: Option<String>, chosen: Option<String>, policy: Option<String>, pro: bool) -> LanguageSettings {
    let (effective, reason) = resolve(system.as_deref(), chosen.as_deref(), policy.as_deref(), pro);
    LanguageSettings {
        system_match: system.as_deref().and_then(match_language).map(String::from),
        system, chosen, policy, effective, reason,
        pro_languages: LANGUAGES.iter().filter(|(_, p)| *p).map(|(c, _)| c.to_string()).collect(),
        languages: LANGUAGES.iter().map(|(c, _)| c.to_string()).collect(),
    }
}
```
