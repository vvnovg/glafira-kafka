# Glafira for Apache Kafka — подпроект C «Контекстные подсказки»

**Дата:** 2026-10-17
**Предыдущие подпроекты:** B1/B2 «Локализация» (8 языков, словари `src/locales/*.json`, проверки `pnpm i18n:check`)
**Следующий подпроект:** D (документация)

Сейчас в интерфейсе около 97 кнопок и 95 полей. Что значат `acks`, идемпотентность, стратегии сброса оффсетов, механизмы SASL или
пресеты топиков, пользователь должен знать сам. Ссылки на документацию не помогут: её не читают. Подпроект C добавляет короткие
всплывающие подсказки там, где без знаний Kafka легко ошибиться.

## 1. Решения

| Вопрос | Решение |
|---|---|
| Где | Только непонятные места: около 45 подсказок (список — §4). У очевидных кнопок и полей подсказок нет |
| Что | 1–2 фразы: что это и когда что выбирать. Без ссылок «подробнее» |
| Как вызывается | Значок «?» рядом с подписью; наведение (300 мс), фокус с клавиатуры, клик закрепляет |
| Позиционирование | `@floating-ui/react`: переворот и сдвиг у краёв окна, портал поверх прокручиваемых панелей |
| Тексты | Словари всех 8 языков, раздел `hints.*`; пишет Claude, носители проверяют выборочно |
| Free / Pro | Подсказки есть во Free и в Pro, в том числе у Pro-функций |
| Отключение | Не нужно: значок ненавязчивый |

Существующие строки-подсказки под полями (`…Hint`, около 7) и системные `title` у значков остаются как есть.

## 2. Компонент `Hint`

`src/components/common/Hint.tsx`, использование: `<Hint k="hints.producer.acks" />`.

- **Значок:** `<button type="button" className="hint-icon">?</button>`, 14 px, цвет `--muted`, в фокусе — обводка `--accent`.
  `aria-label` — `t("hints.label", { name })`, где `name` — видимая подпись поля (проп `label`), например «Подсказка: acks».
- **Показ:** наведение на значок — через 300 мс; фокус с клавиатуры — сразу; клик — показать и закрепить.
- **Скрытие:** уход курсора или потеря фокуса — через 100 мс; если курсор перешёл на саму подсказку, она остаётся
  (текст можно выделить). Закреплённая закрывается вторым кликом, Esc или кликом вне её.
- **Одна открытая подсказка:** открытие новой закрывает предыдущую (общий модульный стор, без контекста React).
- **Позиция:** `placement: "top"`, middleware `offset(6)`, `flip()`, `shift({ padding: 8 })`; рендер в `FloatingPortal`.
- **Вид:** `max-width: 320px`, фон `--bg`, рамка `--border`, тень, `font-size: 12px`, `line-height: 1.4`; светлая и тёмная тема.
- **Доступность:** у подсказки `role="tooltip"` и `id`; у значка `aria-describedby` на этот `id`, пока подсказка открыта.
- **Разметка текста:** через `<Trans>` с компонентом `code` — названия параметров и значений Kafka (`acks`, `all`, `earliest`,
  `compact`) пишутся в `<code>` и не переводятся.

Встраивание: в формах — внутри подписи, после текста (`<label>acks <Hint … /></label>`); у отдельных кнопок и переключателей —
сразу после элемента.

## 3. Тексты

- Раздел `hints` во всех словарях; ключи `hints.<экран>.<поле>`; общий ключ `hints.label` = «Подсказка: {{name}}».
- en — эталон, ru — эталон смысла, Pro-языки — по `docs/i18n/glossary.md`. Новые термины (acks, идемпотентность, сжатие,
  стратегия сброса, ребалансировка и т. п.) сначала вносятся в глоссарий.
- Двойные фигурные скобки в текстах подсказок — только параметры i18next; имена плейсхолдеров Producer в подсказках не пишутся
  (иначе i18next попытается их подставить).
- Длина: en — не больше 200 символов. Схема: что это → когда что выбирать / чем рискуешь.
- Пример (`hints.producer.acks`, en): «How many replicas must confirm a write. <code>all</code> is the safest, <code>1</code> is faster,
  <code>0</code> does not wait and messages can be lost.»

## 4. Список подсказок

| Экран | Ключ `hints.…` | О чём |
|---|---|---|
| Подключение | `connections.environment` | dev/test/prod: цвет, prod требует подтверждения изменений вводом имени (Pro) |
| | `connections.readOnly` | только чтение: запись, сброс оффсетов, удаление и consumer-сессии недоступны |
| | `connections.bootstrap` | один или несколько `host:port` через запятую; остальные брокеры клиент узнает сам |
| | `connections.protocol` | PLAINTEXT / SASL_PLAINTEXT / SSL / SASL_SSL — что шифруется и что аутентифицируется |
| | `connections.saslMechanism` | PLAIN, SCRAM-SHA-256/512: какой выбрать, PLAIN без TLS передаёт пароль открыто |
| | `connections.timeout` | сколько ждать ответа брокера; увеличить для медленных сетей и VPN |
| | `connections.props` | дополнительные параметры librdkafka `key=value`; секреты сюда нельзя |
| | `connections.ca` | CA, которым подписаны сертификаты брокеров; не нужен, если CA уже доверен системой |
| | `connections.caFormat` | PEM, PKCS#12, JKS — в каком формате файл CA |
| | `connections.verifyHostname` | сверять имя брокера с сертификатом; отключать только в тестовых средах |
| | `connections.mtls` | клиентский сертификат, если брокер требует аутентификацию по сертификату |
| | `connections.alias` | имя записи ключа в JKS/PKCS#12, если в хранилище их несколько |
| | `connections.keyPassword` | пароль ключа, если отличается от пароля хранилища / если PEM-ключ зашифрован |
| | `connections.test` | шаги проверки: конфигурация → DNS/TCP → Kafka (TLS, SASL, метаданные); ничего не меняет |
| Топики | `topics.partitions` | параллелизм чтения и порядок: порядок гарантирован только внутри партиции; уменьшить нельзя |
| | `topics.rf` | сколько копий каждой партиции; не больше числа брокеров; 3 — обычный выбор для prod |
| | `topics.preset` | delete — удалять старые сообщения по времени, compact — хранить последнее значение ключа, test — 1 час |
| | `topics.extraConfigs` | любые параметры топика `key=value`, например `retention.ms` |
| | `topics.configReset` | вернуть значение по умолчанию брокера (удалить переопределение) |
| | `topics.configReview` | показать все изменения перед применением; без подтверждения ничего не меняется |
| Сброс оффсетов | `groups.strategyEarliest` | группа перечитает всё, что ещё хранится |
| | `groups.strategyLatest` | группа пропустит всё накопленное и начнёт с новых сообщений |
| | `groups.strategyTimestamp` | первый оффсет с меткой времени не раньше заданной |
| | `groups.strategyOffset` | точный оффсет для каждой выбранной партиции |
| | `groups.strategyShift` | сдвиг текущего оффсета: −N перечитать N сообщений назад, +N пропустить |
| | `groups.scope` | вся группа / выбранные топики / конкретные партиции `topic:partition` |
| | `groups.onlyEmpty` | пока в группе есть активные участники, они перезапишут оффсеты — остановите их |
| | `groups.preview` | показать текущие и новые оффсеты; применяется только после подтверждения |
| | `groups.lag` | сколько сообщений группа ещё не прочитала: конец лога минус закоммиченный оффсет |
| Просмотр | `browse.startPosition` | откуда читать: последние N, с начала, с оффсета, с момента времени, за X минут |
| | `browse.limit` | сколько сообщений показать; большие значения замедляют чтение |
| | `browse.format` | как декодировать ключ и значение: строка, JSON, hex, base64 |
| | `browse.readerNotGroup` | просмотр не вступает в группу и не коммитит оффсеты — кластер не меняется |
| Producer | `producer.partition` | `auto` — партицию выбирает Kafka по ключу; номер — отправить в конкретную |
| | `producer.formats` | как закодировать ключ и значение перед отправкой: строка, JSON, hex, base64 |
| | `producer.placeholders` | плейсхолдеры подставляются заново при каждой отправке: новый UUID, текущее время, номер копии |
| | `producer.acks` | сколько реплик подтверждают запись (`all` / `1` / `0`) |
| | `producer.compression` | сжатие пакетов: меньше трафика, больше CPU; `zstd`/`lz4` — частый выбор |
| | `producer.idempotence` | защита от дублей при повторной отправке; требует `acks = all` |
| | `producer.batchRate` | ограничение скорости пакетной отправки, сообщений в секунду, чтобы не перегрузить кластер |
| Consumer-сессии | `consumer.join` | сессия вступает в группу: участники ребалансируются, коммиты меняют оффсеты группы |
| | `consumer.autoCommit` | коммитить прочитанное автоматически; без него — кнопками «Commit» |
| | `consumer.commit` | «до выбранного» — оффсет следующего сообщения; «всё прочитанное» — по всем партициям |
| | `consumer.pause` | приостановить чтение партиции, не покидая группу |
| Прочее | `common.prodConfirm` | prod-подключение: любое изменение подтверждается вводом имени подключения |

Итого 45 ключей плюс `hints.label`. Точное место каждого значка (компонент и элемент) фиксирует план.

## 5. Проверки

Расширение `scripts/i18n-check.mjs`:
- каждый `k="hints.…"` из `<Hint>` в `src/` есть в en.json (как уже проверяются статические ключи `t("…")`);
- каждый ключ `hints.*` из en.json, кроме `hints.label`, используется хотя бы в одном `<Hint k="…">` — мёртвых подсказок нет;
- en `hints.*` — не длиннее 200 символов (без учёта тегов).

## 6. Тесты

- `Hint.test.tsx` (поддельные таймеры): показ через 300 мс при наведении; сразу при фокусе; скрытие при уходе курсора и Esc;
  клик закрепляет, второй клик закрывает; открыта только одна подсказка; `role="tooltip"` и `aria-describedby`; `<code>` в тексте.
- Тесты экранов: число значков на экране и текст одной открытой подсказки.
- `src/i18n/locales.test.ts` и `pnpm i18n:check` автоматически покрывают новые ключи во всех языках.

## 7. Смоук `docs/smoke/c.md`

Все подсказки на всех экранах; у правого и нижнего края окна, в левой панели и в колонке деталей; светлая и тёмная тема;
с клавиатуры (Tab, Esc); ru и один Pro-язык; окно 900 px.

## 8. Объём и порядок

Один план: компонент и проверки → экраны (подключение; топики и конфигурация; группы; просмотр; Producer; consumer-сессии и прочее),
каждая задача — en и ru → Pro-языки (2–3 задачи) → смоук и документация (`docs/i18n/README.md` — раздел о подсказках).

## 9. Вне объёма

Подсказки у очевидных элементов, в заголовках колонок и диалогах подтверждения; ссылки на документацию; обучающий тур;
настройка отключения подсказок; подсказки к параметрам конфигурации топика из ответа брокера (их описания приходят от Kafka).
