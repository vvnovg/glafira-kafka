# Glafira for Apache Kafka — подпроект D «Руководство пользователя»

**Дата:** 2026-10-17
**Предыдущие подпроекты:** B (8 языков, словари, глоссарий), C (подсказки «?»), папки подключений.

Руководства для пользователя нет: README — для разработчика, `docs/admin.md` — для администраторов. Подпроект D добавляет
руководство на 8 языках, встроенное в приложение (работает без интернета, в том числе в закрытых корпоративных сетях) и
опубликованное в репозитории релизов.

## 1. Решения

| Вопрос | Решение |
|---|---|
| Где читать | Вкладка «Справка» в приложении (офлайн) + те же главы Markdown в `vvnovg/glafira-kafka-releases/guide/` |
| Языки | Все 8 (en, ru, de, fr, es, it, pl, pt-BR); справка — на языке интерфейса; перевод с en по `docs/i18n/glossary.md` |
| Скриншоты | Нет; названия элементов интерфейса — метками из словарей |
| Названия кнопок | Метка `[[ui:ключ]]` в исходнике → жирное значение из словаря текущего языка (в приложении и при публикации) |
| Вход | «Справка» внизу левой панели; F1 (глава текущего экрана); на macOS — меню Help |
| Free / Pro | Руководство доступно всем; глава о consumer-сессиях помечает функцию как Pro |

## 2. Содержание

Исходники: `docs/guide/<код>/<глава>.md`, одинаковый набор файлов во всех языках:

| Файл | Глава |
|---|---|
| `getting-started.md` | Начало работы: установка (macOS, Windows, Linux; снятие карантина на macOS), первый запуск, локальный стенд (`docker compose -f dev/docker-compose.yml up -d`), языки и «Настройки» |
| `connections.md` | Подключения: создание и проверка, протоколы, SASL, SSL и mTLS (форматы сертификатов, пароли в системном хранилище), окружения и prod, «только чтение», папки, экспорт и импорт |
| `topics.md` | Кластер и топики: обзор кластера, список топиков и фильтры, создание (пресеты, партиции, RF), удаление, конфигурация и её изменение, параметры топика |
| `browse.md` | Просмотр сообщений: стартовые позиции, фильтры, форматы, детали сообщения, экспорт, «открыть в Producer», «сбросить группу сюда» |
| `producer.md` | Producer: одиночная отправка, форматы и заголовки, плейсхолдеры, шаблоны и история, пакетная отправка (N копий, JSON Lines и CSV, скорость), `acks`, сжатие, идемпотентность |
| `groups.md` | Consumer groups: список и лаг, детали группы, сброс оффсетов (стратегии, область, предпросмотр), удаление |
| `consumer-sessions.md` | Consumer-сессии (Pro): чтение как участник группы, коммиты, пауза партиций, журнал ребалансировок |
| `license-updates.md` | Лицензия и обновления: Free и Pro, активация ключа, обновления, «О программе», диагностика |
| `troubleshooting.md` | Решение проблем: частые ошибки подключения (DNS, TLS, SASL, таймауты) с текстами ошибок, где лежат логи, что приложить к обращению |

Политики организации — в `docs/admin.md`; руководство только упоминает, что часть настроек может задать организация.
Ориентир — 25–35 страниц текста на язык.

**Правила текста:**
- первая строка главы — `# Заголовок`; разделы — `##` с явными якорями `{#mtls}` (одинаковыми во всех языках, латиница, kebab-case);
- элемент интерфейса — метка `[[ui:ключ]]`, ключ без параметров `{{…}}`; если подходящего ключа нет — сначала добавить ключ в словари;
- ссылки между главами — `[текст](connections.md#mtls)`; внешние ссылки — только `https://`;
- значения и команды — в `` `code` ``; стиль, обращение и термины — по `docs/i18n/glossary.md`.

## 3. Справка в приложении

- **Загрузка:** `import.meta.glob("../../docs/guide/*/*.md", { query: "?raw" })` — ленивые модули; при открытии справки
  загружаются главы текущего языка.
- **Разбор:** якоря `{#id}` у заголовков `##`; метки `[[ui:ключ]]` → `**значение**` через `t(ключ)` перед рендером.
- **Рендер:** `react-markdown` (без `dangerouslySetInnerHTML`, без сырого HTML). Ссылка `глава.md#якорь` — переход внутри
  вкладки; `https://…` — в системном браузере через `@tauri-apps/plugin-opener`; прочие ссылки не активны.
- **Вкладка «Справка»:** оглавление слева (главы и разделы `##`), текст справа, поле поиска сверху — поиск без учёта регистра
  по тексту разделов текущего языка (после подстановки меток), список совпадений «глава › раздел», клик — переход к разделу.
- **Вход:** «Справка» внизу левой панели (рядом с «О программе»); F1 в любом месте окна — глава текущего экрана:

| Экран (вкладка) | Глава |
|---|---|
| форма подключения | `connections` |
| обзор кластера, топики, детали топика | `topics` |
| просмотр сообщений | `browse` |
| Producer | `producer` |
| группы, детали группы, сброс оффсетов | `groups` |
| consumer-сессия | `consumer-sessions` |
| «Лицензия», «О программе» | `license-updates` |
| прочее / нет вкладки | `getting-started` |

- **Язык:** как у интерфейса; смена языка перерисовывает открытую справку.
- **Меню macOS:** меню Help строится из фронтенда (`@tauri-apps/api/menu`) с подписями из словарей и перестраивается при смене
  языка: «Руководство Glafira» (⌘?), «Решение проблем», разделитель, «О программе», «Собрать диагностику…». Остальные меню —
  системные. На Windows и Linux строка меню не добавляется.

## 4. Публикация

- `scripts/guide-publish.mjs <out>`: для каждого языка подставляет метки (значение ключа из `src/locales/<код>.json` в `**…**`),
  убирает `{#id}`-якоря, заменяя их HTML-якорем `<a id="id"></a>` перед заголовком (GitHub), сохраняет ссылки между главами,
  пишет `<out>/<код>/*.md` и `<out>/README.md` (языки и оглавление).
- `.github/workflows/release.yml`, шаг publish: собрать руководство и положить в каталог `guide/` репозитория
  `vvnovg/glafira-kafka-releases` тем же коммитом, что обновляет README релизов; в README репозитория релизов — строка
  «Руководство: English · Русский · …» со ссылками.

## 5. Проверки (`scripts/i18n-check.mjs`, CI)

- у каждого языка из `src/i18n/languages.ts` — один и тот же набор глав;
- одинаковые наборы якорей `{#id}` по главам во всех языках;
- каждая метка `[[ui:ключ]]` — существующий ключ en без параметров;
- ссылки `глава.md#якорь` ведут на существующую главу и якорь; ссылки на файлы вне `docs/guide` запрещены;
- каждая глава начинается с `# `.

## 6. Тесты

- Разбор главы: якоря, метки → жирные значения текущего языка, неизвестная метка — видимая ошибка в тесте (проверка в CI её не пропустит).
- Вкладка: оглавление, переход по внутренней ссылке, внешняя ссылка вызывает `opener`, поиск находит раздел, смена языка перерисовывает.
- F1 открывает главу текущего экрана; «Справка» в левой панели открывает вкладку.
- Меню Help: строится с подписями текущего языка и перестраивается при смене языка (мок `@tauri-apps/api/menu`); не строится вне macOS.
- `guide-publish.mjs`: метки подставлены, якоря преобразованы, README со всеми языками.
- Проверки §5 — тесты скрипта.

## 7. Порядок работы

Механизм (вкладка, рендер, поиск, F1, меню, проверки, заготовки глав) → тексты en и ru по главам (3–4 задачи) → переводы на
6 Pro-языков (2–3 задачи) → публикация в репозиторий релизов, смоук `docs/smoke/guide.md`. Одна ветка.

## 8. Вне объёма

Скриншоты и видео; руководство администратора (есть `docs/admin.md`); справка по каждому полю (есть подсказки «?»);
отдельный сайт; меню на Windows и Linux.
