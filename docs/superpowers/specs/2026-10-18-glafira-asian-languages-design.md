# Glafira for Apache Kafka — подпроект E «Азиатские языки, все языки бесплатно»

**Дата:** 2026-10-18
**Предыдущие подпроекты:** B (8 языков, словари, глоссарий, проверки), C (подсказки), D (руководство на 8 языках).

Цель — охват разработчиков: добавить китайский (упрощённый и традиционный), японский и корейский и сделать все языки
бесплатными. Pro остаётся тарифом функций (consumer-сессии, prod-режим, дальше — M4), а не языков.

## 1. Решения

| Вопрос | Решение |
|---|---|
| Новые языки | `zh-CN` 简体中文, `zh-TW` 繁體中文, `ja` 日本語, `ko` 한국어 |
| Тариф языков | Все 12 языков — Free. Концепция «Pro-язык» удаляется из кода, словарей, руководства и документации |
| Объём перевода | Словарь интерфейса (включая подсказки `hints.*`) и 9 глав руководства на каждый новый язык |
| `zh-TW` | Отдельный перевод с тайваньской лексикой, не конвертация из `zh-CN` |
| Шрифты | Системные; атрибут `lang` документа = код языка (начертание иероглифов зависит от языка) |
| Вторая волна (vi, id, tr), зеркало для Китая, локализация установщиков | Вне объёма |

## 2. Языки бесплатно

- Rust (`src-tauri/src/settings.rs`, команда выбора языка): убрать признак Pro у языков, проверку лицензии при выборе,
  причину `ProRequired` и поле `pro_languages`; `resolve` — политика → выбор → ОС → en без учёта лицензии.
- Фронтенд: убрать флаг `pro` из `src/i18n/languages.ts`, суффикс «— Pro» и подсказку о Pro в «Настройках»; удалить ключи
  `settings.language.proSuffix` и `settings.language.proRequired` из всех словарей.
- Тексты: экран «Лицензия» (что даёт Pro), руководство (`getting-started`, `license-updates` и любые другие упоминания Pro-языков —
  во всех языках), `README.md`, `docs/licensing.md`, `docs/admin.md`, `docs/i18n/*`, смоук-документы — «все языки бесплатно».
- Поведение: пользователь, у которого был выбран бывший Pro-язык без лицензии, сразу получает его.

## 3. Новые языки

**Сопоставление языка ОС** (`match_language` в Rust):

| Язык ОС | Код |
|---|---|
| `zh-Hans*`, `zh-CN`, `zh-SG`, `zh` | `zh-CN` |
| `zh-Hant*`, `zh-TW`, `zh-HK`, `zh-MO` | `zh-TW` |
| `ja*` | `ja` |
| `ko*` | `ko` |

**Правила письма** (новые столбцы и раздел в `docs/i18n/glossary.md`):
- **zh-CN / zh-TW:** полноширинная пунктуация «，。：；？！（）»; кавычки “…” (`zh-CN`) и 「…」 (`zh-TW`); пробел между иероглифами и
  латиницей или цифрами («连接 Kafka 集群»); без пробелов между иероглифами; `zh-TW` — тайваньская лексика (檔案, 程式, 設定…).
- **ja:** стиль です/ます в тексте, на кнопках — краткие формы; заимствования катаканой по глоссарию (トピック, オフセット,
  コンシューマーグループ…); полноширинная пунктуация, кавычки 「…」, без пробелов между словами.
- **ko:** официально-вежливый стиль (-습니다), на кнопках — существительные или краткие формы; пробелы между словами; ASCII-пунктуация.
- Множественное число — одна форма `other` (по `Intl.PluralRules`); названия Kafka, протоколов и форматов — как в глоссарии.

**Руководство:** для `zh-CN`, `zh-TW`, `ja` метки `[[ui:…]]` ставятся без пробелов вокруг; жирное `**…**` вплотную к иероглифам
должно рендериться и в приложении (`src/guide/parse.ts` + react-markdown), и в GitHub (публикация `scripts/guide-publish.mjs`).

## 4. Проверки (`scripts/i18n-check.mjs`, CI)

- `zh-CN`, `zh-TW`, `ja` (словари и главы руководства, вне `code`): нет полуширинной пунктуации `, . : ; ? !` сразу после иероглифа.
- `zh-CN`, `zh-TW`: нет пробела между двумя иероглифами.
- Отчёт о длине (`--lengths`): ширина строки для этих языков считается по видимой ширине (иероглиф, кана, хангыль ≈ 2 латинских символа).
- Существующие проверки (ключи, параметры, теги, метки, якоря, ссылки, совпадения с en, список языков) распространяются на новые языки
  без изменений.

## 5. Тесты

- Переключение на каждый новый язык; `document.documentElement.lang` = код языка.
- `match_language`: каждая строка таблицы §3.
- Нет Pro-ограничения языка: Rust (`resolve`, команда выбора) и «Настройки» (нет суффикса, все языки выбираются без лицензии).
- Жирная метка вплотную к иероглифам: разбор главы в приложении и `publishChapter`.
- Существующий тест словарей покрывает формы множественного числа и загрузку новых словарей.

## 6. Порядок работы

Одна ветка: языки бесплатно (код, словари, руководство, документация) → инфраструктура новых языков (список, сопоставление ОС,
глоссарий, проверки, заготовки) → словари `zh-CN`, `zh-TW`, `ja`, `ko` (по задаче на язык) → руководство на каждом языке
(по задаче на язык) → документация и смоук `docs/smoke/e.md`. Перед выпуском — выборочная проверка носителями по
`docs/i18n/review-checklist.md` (особенно `ja`).

## 7. Вне объёма

системный поиск в меню macOS.
