# Glafira for Apache Kafka — этап U1 «Ревизия интерфейса под macOS»

**Дата:** 2026-11-06
**Зачем:** Glafira выглядит как утилитарный веб в окне: кегль ниже нормы HIG, значки из символов шрифта,
стандартный заголовок окна поверх панелей, нет колец фокуса и системных сочетаний клавиш, дерево подключений
в каждом продукте семейства нарисовано по-своему. Этап приводит оболочку к виду нативного приложения, не меняя
информационную архитектуру и поведение экранов.

**Основа:** прототип на канвасе (главное окно «сейчас / предложение», доска деталей, доска единого дерева),
принят 2026-11-06. Kafka-версия — источник общих файлов для Glafira for Kubernetes, PostgreSQL и LLM Inference
(`PORTED.md` в каждом из них); после U1 правки переносятся туда тем же путём.
**Ветка:** `feat/ui-revision` от `main` (0.5.5). После слияния — выпуск 0.6.0.

Новых функций нет; новые строки интерфейса — только подписи значков и сочетаний, по возможности из уже существующих
ключей.

## 1. Решения

| Вопрос | Решение |
|---|---|
| Минимальный кегль | 11 px; подписи полей и статистика 12 px; бейджи 11 px; основной текст 13 px; заголовок страницы 17/600 |
| Значки | Один компонент `Icon` с SVG 16 px, обводка 1.5, цвет `currentColor`; символы шрифта и emoji из разметки уходят |
| Цвета | Акцент и семантика по палитре macOS (`#007AFF` / `#0A84FF`, красный, оранжевый, зелёный); у тёмной темы свои тона панели, полей и элементов управления |
| Фокус | `:focus-visible` на всех элементах управления: кольцо 3 px акцентом на 40 %; выделение в списках и дереве — заливка акцентом с белым текстом |
| Окно (macOS) | `titleBarStyle: Overlay`, `hiddenTitle`: светофор внутри боковой панели, панель вкладок и верх боковой панели — область перетаскивания |
| Окно (все ОС) | `tauri-plugin-window-state`: размер и положение запоминаются; боковая панель 248 px с изменяемой шириной 200–400, значение в `localStorage` |
| Дерево | Единый `TreeRow`: строка 24 px, отступ уровня 14 px, колонка шеврона 16 px, иконка типа, имя, дополнительный текст справа; направляющие уровней 1 px |
| Вкладки | Панель 52 px на macOS (36 на других ОС), вкладки-сегменты, полоса окружения 2 px под панелью |
| Таблицы | Шапка липкая, строки через одну с подложкой 3 %, выделенная строка — акцентом |
| Клавиши | ⌘N, ⌘W, ⇧⌘W, ⌘R, ⌘F, ⇧⌘F, ⌘1…⌘9, ⌃Tab, ⌃⇧Tab, ⌘, ; на macOS через меню приложения, на Windows и Linux через `keydown` (Ctrl) |
| Анимации | Нет, как и прежде; `prefers-reduced-motion` соблюдать нечему |
| Порядок переноса | Kafka → Kubernetes → PostgreSQL → LLM Inference; у PostgreSQL дерево глубже всех, его доска прототипа задаёт геометрию |

## 2. Токены (`src/styles.css`)

Светлая тема:

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#ffffff` | фон рабочей области |
| `--bg-alt` | `#f2f2f4` | шапки таблиц, подложки |
| `--sidebar` | `#f5f5f7` | боковая панель и панель вкладок |
| `--control` | `#ffffff` | кнопки, поля |
| `--field` | `#ffffff` | поля ввода |
| `--fg` | `#1d1d1f` | текст |
| `--muted` | `#6e6e73` | вторичный текст (5,3:1 на `--bg`) |
| `--border` | `#e1e1e5` | рамки |
| `--accent` | `#007aff` | акцент |
| `--danger` | `#d70015` | красный текст опасных действий (5,0:1 на белом; системный `#ff3b30` даёт 3,5:1) |
| `--badge-danger` | `#d70015` | заливка бейджа PROD в обеих темах (белый текст 5,0:1) |
| `--warn` | `#ff9500` | предупреждения, STAGE |
| `--ok` | `#34c759` | TEST, состояние «подключено» |
| `--llm-badge` | `#2563eb` | как прежде: контраст текста 5,2:1 |
| `--shadow` | `0 .5px 1px rgba(0,0,0,.12)` | кнопки и поля |
| `--ring` | `0 0 0 3px color-mix(in srgb, var(--accent) 40%, transparent)` | кольцо фокуса |
| `--radius` | `6px` | кнопки, поля, карточки |
| `--row` | `24px` | высота строки дерева и элементов управления |

Тёмная тема (`prefers-color-scheme: dark`): `--bg #1e1f22`, `--bg-alt #2a2b2f`, `--sidebar #232428`, `--control #303135`,
`--field #1a1b1e`, `--fg #e8e8ea`, `--muted #9c9ca3` (6,4:1), `--border #3a3b40`, `--accent #0a84ff`, `--danger #ff453a`
(4,9:1 на `--bg`), `--badge-danger #d70015`, `--warn #ff9f0a`, `--ok #30d158`, `--llm-badge #60a5fa`, `--shadow none`.

Цвета окружений (`src/lib/env.ts`) переходят на ту же палитру: `local` — `--muted`, `dev` — акцент, `test` — `--ok`,
`stage` — `--warn`, `prod` — `--badge-danger`. В тёмной теме значения берутся из токенов, поэтому `ENV_COLORS` возвращает
`var(--…)`, а не hex.

Контрастные пары, которые проверяет `styles.test.ts`: `--muted` на `--bg` и на `--sidebar` в обеих темах не ниже 4,5:1;
`--danger` на `--bg` и белый на `--badge-danger` не ниже 4,5:1; тёмный текст на `--warn` и `--ok` не ниже 4,5:1 (бейджи
STAGE и TEST получают тёмный текст); белый на `--accent` не ниже 3,5:1 — как у системного выделения macOS, порог
WCAG для элементов управления.

## 3. Типографика

- `:root` — 13 px, `line-height 1.4`; `code`, `pre` — 12 px.
- Заголовок экрана (`.toolbar h2`) — 17 px / 600, межбуквенный −0,01em; `h3` блоков — 14 px / 600; `h4` — 13 px / 600.
- Подписи полей (`.browse-form .field > span`, `.form label`, `.stats dt`) — 12 px; `.stats dd` — 17 px.
- Бейджи окружения и LLM — 11 px / 600, высота 16 px, скругление 4 px; `.sev`, `.sev-count` — 12 px.
- Таблицы: шапка 12 px / 600, тело 13 px; числа в столбцах — `font-variant-numeric: tabular-nums`.
- Правило: ни одного `font-size` ниже 11 px в `styles.css`; это проверяет тест `styles.test.ts`.

## 4. Элементы управления

- `button`: высота 24 px, `padding 0 10px`, скругление 6 px, фон `--control`, рамка `--border`, тень `--shadow`;
  `.primary` — акцент с белым текстом; `.danger` — красный текст; `.icon` — 24×24 без рамки, цвет `--muted`, при наведении
  `--fg`; `.link` — как прежде.
- `input`, `select`, `textarea`: высота 24 px (textarea — авто), скругление 6 px, фон `--field`; `type="search"` —
  скругление 7 px, значок поиска слева через `.search-field` (обёртка с `Icon`).
- `:focus-visible` для всех: `outline: none; box-shadow: var(--ring); border-color: var(--accent)`. У строк дерева и
  списков — то же кольцо внутрь (`inset`).
- Подсказка `Hint`: значок `Icon name="help"` 16 px вместо символа «?» в круге; поведение без изменений.
- Подвкладки `.subtabs`: сегментированный контрол — подложка `--control`, активный сегмент `--bg` (в тёмной теме `#4a4b50`)
  с тенью, 12 px отступы.
- Карточки `fieldset`: скругление 8 px, фон `color-mix(--fg 3%)`, `legend` 12 px / 600 капителью.

## 5. Значки

`src/components/common/Icon.tsx`: `<Icon name="plus" />` рисует `<svg viewBox="0 0 16 16" width=16 height=16
aria-hidden="true">` из таблицы путей; обводка 1.5, `stroke-linecap round`. Значок без подписи всегда внутри `<button>`
с `aria-label`. Набор (имя → назначение):

`plus` добавить · `folderPlus` папка · `folder` папка в дереве · `more` меню «ещё» · `pencil` править · `close` закрыть ·
`chevron` раскрыть (поворот 90° в раскрытом состоянии) · `warning` внимание · `lock` read-only · `help` подсказка ·
`refresh` обновить · `send` отправить · `users` группы · `play` читать · `stop` остановить · `copy` копировать ·
`search` поиск · `settings` настройки · `heart` поддержать · `book` справка · `info` о программе · `grid` обзор ·
`list` топики · `flag` замечания · `dot` состояние (заливка).

Замена в разметке: `Layout` и `UpdateNotice` («×» → `close`), `HeadersEditor` («×» → `close`), `GroupList` и
`TopicList` («●» → `dot`), `parts.tsx` (`SeverityMark`: «●» → `dot` цветом строгости), `ConfigTable` и `EnvBadge`
(«🔒» → `lock`), `ConnectionTree` («+», «+📁», «⋯», «▾/▸» → `plus`, `folderPlus`, `more`, `chevron`), `ConnectionNode`
(«✎» → `pencil`), `Hint` («?» → `help`), `McpIndicator` (`::before "● "` → `dot` в разметке).

## 6. Дерево подключений

Компонент `TreeRow` (`src/components/connections/tree/TreeRow.tsx`): строка 24 px, `padding-left: 8px + depth × 14px`,
скругление 6 px, содержимое — `chevron` (или пустая колонка 16 px у листа), `Icon` типа, имя с обрезкой «…»,
дополнительный текст `.tree-extra` 12 px справа, бейджи. Вся строка — одна кнопка или `div` с `activateProps`;
`aria-current="page"` у листа, чья вкладка активна, и класс `.current` с заливкой акцентом.

Направляющие: у каждого вложенного `ul` псевдоэлемент `::before` — линия 1 px по центру колонки шеврона родителя
(`left: -6px` при `padding-left: 14px`), цвет `color-mix(--fg 9%)`; у `ul` с открытой веткой (`.tree-open`) — 22 %.

Kafka: папка (`folder`), подключение (точка состояния вместо иконки, бейдж окружения, `LLM`, `lock`), шесть листов
с иконками: `grid` обзор, `list` топики, `users` группы, `flag` замечания (счётчик строгости справа), `send` producer,
`play` consumer. Пункт «✎ править» остаётся кнопкой в строке подключения, видимой при наведении и фокусе.

Заголовок панели «Подключения» — капитель 12 px `--muted` с тремя `button.icon` (`plus`, `folderPlus`, `more`);
фильтр — `.search-field`. Нижняя панель — четыре строки с иконками (`settings`, `heart`, `book`, `info`) того же
`TreeRow` без отступа; индикатор MCP над ними.

На macOS над заголовком — полоса 52 px `.sidebar-top` с `data-tauri-drag-region` (место светофора).

## 7. Окно и раскладка

- `tauri.conf.json`: у окна `"titleBarStyle": "Overlay"`, `"hiddenTitle": true` (macOS; другие ОС игнорируют).
- Rust: `tauri_plugin_window_state` (`Builder::default().build()`), запоминает размер и положение; в capabilities —
  `window-state:default`.
- Панель вкладок `.tabbar`: на macOS 52 px с `data-tauri-drag-region` на пустом месте, иначе 36 px; фон `--sidebar`;
  вкладка — сегмент 28 px со скруглением 7 px, активная — `--control` с тенью; кнопка закрытия — `Icon close` 14 px,
  видна у активной и при наведении.
- `.env-stripe` переезжает под панель вкладок: 2 px цветом окружения.
- Разделитель боковой панели `.sidebar-splitter` (6 px, курсор `col-resize`): перетаскивание меняет ширину 200–400 px,
  значение в `localStorage` `glafira.sidebar.width`; двойной клик возвращает 248. Хук `useResizable` общий — им же
  позже получит ширину панель деталей сообщения.
- `isMacOS()` переезжает из `useAppMenu` в `src/lib/platform.ts`.

## 8. Клавиши и меню

На macOS меню строится целиком (`Menu.new`), а не из `Menu.default()`: у стандартного `File` и `Window` пункт
«Закрыть окно» занимает ⌘W.

| Меню | Пункт | Клавиши | Действие |
|---|---|---|---|
| Glafira | О программе, Настройки…, Services, Hide, Hide Others, Quit | ⌘, у «Настройки…» | вкладка настроек |
| File | Новое подключение | ⌘N | форма подключения |
| File | Закрыть вкладку | ⌘W | закрыть активную |
| File | Закрыть окно | ⇧⌘W | `getCurrentWindow().close()` |
| Edit | Undo, Redo, Cut, Copy, Paste, Select All | стандартные | предопределённые |
| View | Обновить | ⌘R | кнопка `[data-action="refresh"]` активной вкладки |
| View | Найти | ⌘F | поле `[data-action="filter"]` активной вкладки, иначе фильтр дерева |
| View | Фильтр подключений | ⇧⌘F | фильтр дерева |
| View | Полный экран | стандартный | предопределённый |
| Window | Minimize, Zoom, Следующая вкладка, Предыдущая вкладка | ⌃Tab, ⌃⇧Tab | переключение |
| Help | как сейчас | ⇧⌘/ | как сейчас |

⌘1…⌘9 — вкладка по номеру, на всех ОС через `keydown` (в меню не выносится). На Windows и Linux все сочетания —
хук `useShortcuts` (`Ctrl` вместо ⌘), на macOS он обрабатывает только то, чего нет в меню. F1 — как прежде.

Кнопки «Обновить» на экранах получают `data-action="refresh"`, фильтры списков — `data-action="filter"`;
обработчик ищет их внутри видимой `.tab-content` и вызывает `click()` или `focus()`.

Новые ключи словаря: `menu.file`, `menu.newConnection`, `menu.closeTab`, `menu.closeWindow`, `menu.view`,
`menu.refresh`, `menu.find`, `menu.filterConnections`, `menu.window`, `menu.nextTab`, `menu.prevTab`, `menu.settings`
— на 12 языках.

## 9. Тесты

- `src/styles.test.ts`: `styles.css` текстом — нет `font-size` меньше 11 px; нет символов `✎⋯●▸▾🔒` в `src/components`
  (кроме тестов и комментариев); токены обеих тем присутствуют; контраст пар из §2 не ниже порога (функция
  относительной яркости в тесте).
- `Icon.test.tsx`: у каждого имени есть путь; `aria-hidden`.
- `TreeRow.test.tsx`: отступ по глубине, `aria-current`, кнопка шеврона с `aria-expanded`.
- `useShortcuts.test.ts`: ⌘W закрывает активную вкладку, ⌘1 активирует первую, ⌘R кликает кнопку обновления видимой
  вкладки, на macOS хук не перехватывает то, что есть в меню.
- Существующие тесты дерева и раскладки адаптируются к новым подписям кнопок (имена через `aria-label`, не текст).
- `pnpm i18n:check --require-all-languages`, `pnpm build`, `cargo check`.
